# La Guestation Collection — Digital books

Scan the table QR code → choose the website, the La Guestation book or the L'AZURÉA Residences book.

- `index.html` — welcome page (QR code target)
- `guestation/` — La Guestation book (17 pages)
- `lazurea/` — L'AZURÉA Residences book (10 spreads)
- To replace pages: overwrite `pages/pXX.jpg` (and `thumbs/pXX.jpg`) keeping the same names.
